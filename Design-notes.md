This document outlines the visual design guidelines, interface components, and usability principles for the Unichild International School website designed by Team DevForge.

## 3. Colour Palette

The website uses yellow and black as its primary visual colours.

* **Primary Colour:** Yellow (`#FFC107`) — used for primary actions and important interface highlights, where appropriate.
* **Secondary Colour:** Black (`#000000`) — used for headings, text, navigation elements, and other interface elements where appropriate.
* **Background Colour:** Use the background colours defined in the approved Figma design.
* **Text Colour:** Maintain sufficient contrast between text and its background for readability.

*Note: Confirm the exact HEX values in Figma before implementation.*

## 4. Typography

* **Font Family:** Inter
* **Body Text:** Inter Regular
* **Buttons and Form Labels:** Inter Regular, where specified in the design.
* **Headings:** Follow the font family, weight, and size defined in Figma.
* **Readability:** Maintain consistent font sizes, line heights, and spacing.

## 5. Layout and Spacing

* Follow the page layouts and alignment shown in Figma.
* Maintain consistent spacing between sections, cards, form fields, and buttons.
* Use a clear visual hierarchy to distinguish headings, content, and primary actions.
* Keep the interface organized and easy to navigate.

## 6. UI Components

The following components should follow the approved Figma designs:

* Navigation bar and menus
* Buttons and links
* Input fields and forms
* Cards and dashboard panels
* Tables and data displays, where required
* Notifications and alert messages
* Icons and other visual elements

Reusable components should maintain consistent styling and behaviour across the website.

## 7. Responsive Design

* Adapt the interface to desktop, tablet, and mobile screen sizes as required.
* Ensure that navigation, forms, dashboards, and other components remain usable on smaller screens.
* Prevent text overflow, overlapping elements, and horizontal scrolling where avoidable.
* Follow the responsive layouts or behaviour documented in Figma.

## 8. Accessibility and Usability

* Maintain sufficient colour contrast between text and backgrounds.
* Use clear labels for form fields and meaningful error messages.
* Make buttons and interactive elements easy to identify.
* Provide visible feedback when users submit forms or perform actions.
* Ensure that interactive elements can be used with a keyboard where applicable.

## 9. Design Consistency

* Use the approved colour palette and typography consistently.
* Avoid introducing new colours, fonts, or components without agreement from the team.
* Use the same component styles for similar actions across different pages.
* Refer to Figma when implementation details are unclear.

## 10. Developer Handoff

Developers should use this document alongside the Figma design file, prototype, and user-flow documentation.

Any significant differences between the implementation and the approved design should be discussed with the UI/UX designer before finalizing the interface.
