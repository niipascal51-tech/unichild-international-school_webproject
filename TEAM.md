## 3. Team Collaboration

Team members are expected to:

* Communicate respectfully and share relevant project updates.
* Complete assigned tasks within agreed timelines.
* Keep project documentation consistent with actual project progress.
* Use GitHub issues to track tasks and outstanding work.
* Review changes through the team's agreed pull-request process.
* Report problems and dependencies as early as possible.
* Support testing and verification where appropriate.
* Avoid committing passwords, API keys, or confidential student information.

## 4. Version Control

The GitHub repository serves as the team's shared workspace for project source code, documentation, issue tracking, and review evidence.

Contributors should follow the team's agreed branching, commit, and pull-request procedures.

Changes should be reviewed and tested as appropriate before they are accepted into the main development branch.

## 5. Documentation Responsibilities

The Documentation and Deployment role is responsible for helping maintain:

* `README.md`
* `TEAM.md`
* Project documentation in `docs/`
* Deployment instructions and supporting evidence
* Documentation links and repository organization
* Relevant project handover documentation

These responsibilities should be coordinated with other team members so that the documents reflect the actual implementation.

## 6. Responsible Use of AI

All team members must follow the team's agreed AI usage policy.

AI-assisted contributions should be recorded in `AI_USAGE_LOG.md`, reviewed, and verified before acceptance.

Each contributor remains responsible for understanding and explaining their own work.

Client and student information must not be disclosed through inappropriate tools or public services.
